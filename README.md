виконання (`results/`). Усі роботи одним архівом: `OP_Lab_Odarchuk_v19.zip`.

## Компіляція

```sh
make -C Lab1                                    # скомпілювати одну роботу
for i in $(seq 1 11); do make -C Lab$i; done    # скомпілювати всі
make -C Lab1 run1                               # скомпілювати й запустити завдання 1
```

Прапорці: `gcc -std=c17` та `g++ -std=c++17`, обидва з `-Wall -Wextra -pedantic -O2`.
